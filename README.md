# Gemma 3 Web Interface (Ollama)

Проект для общения с моделью **Gemma 3** через **Ollama** с самописным веб-интерфейсом в стиле ChatGPT.

## Структура проекта

```
aotk_project/
├── setup.sh              # Исполнительный файл установки (запуск в терминале Ubuntu)
├── run.sh                # Исполнительный файл запуска бэкенда
├── README.md             # Этот файл
├── backend/
│   ├── app.py            # Flask бэкенд + Ollama API
│   └── requirements.txt  # Python зависимости
├── frontend/
│   ├── index.html        # HTML шаблон интерфейса
│   ├── style.css         # Стили (дизайн в стиле ChatGPT, тёмная тема)
│   └── script.js         # Логика интерфейса (сессии, изображения, SSE)
├── sessions/             # Хранение сессий (JSON) — создаётся автоматически
└── uploads/              # Загруженные изображения — создаётся автоматически
```

## Возможности

- 🤖 Модель **Gemma 3** через Ollama (мультимодальная — текст + изображения)
- 💬 Несколько чат-сессий (создание, переключение, удаление, автосохранение)
- 🖼️ Отправка фотографий в чат (предпросмотр перед отправкой)
- ⚡ Потоковый ответ модели в реальном времени (токен за токеном)
- 🎨 Дизайн в стиле ChatGPT (тёмная тема, адаптив)
- 🐧 Вся установка — только через терминал Ubuntu (без десктопных приложений)

## Быстрый старт (в терминале Ubuntu)

Проект размещается в папке `~/ai`.

```bash
# 1. Скопируйте папку проекта на Ubuntu (если ещё не скопировали)
#    С вашего основного компьютера выполните, например:
#    scp -r aotk_project/* username@ubuntu-server:~/ai/

# 2. Перейдите в папку проекта
cd ~/ai

# 3. Сделайте скрипты исполняемыми и запустите установку
chmod +x setup.sh run.sh
./setup.sh
```

Скрипт `setup.sh` сам:
- установит Ollama (если не установлен),
- запустит `ollama serve` в фоне,
- скачает модель `gemma3`,
- установит Python 3 и зависимости (Flask, flask-cors, requests),
- сделает `run.sh` исполняемым.

Затем запустите проект:

```bash
./run.sh
```

Бэкенд будет доступен по адресу: **http://localhost:5000**

Откройте в браузере файл `frontend/index.html` (или перейдите на http://localhost:5000, если бэкенд отдаёт статику).

## Ручная установка (если setup.sh не подошёл)

```bash
# Установка Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Запуск сервера Ollama
ollama serve &

# Скачивание модели
ollama pull gemma3

# Установка Python зависимостей
sudo apt-get update -y
sudo apt-get install -y python3 python3-pip
pip3 install -r backend/requirements.txt

# Запуск
./run.sh
```

## Доступ из локальной сети

Бэкен запускается на `0.0.0.0:5000`, поэтому он доступен для других компьютеров в той же локальной сети.

### 1. Узнайте IP-адрес сервера
На сервере (где запущен проект) выполните:
```bash
hostname -I
# или
ip addr
```
Пример вывода: `192.168.1.42`

### 2. Откройте порт 5000 в брандмауэре Ubuntu (ufw)
```bash
sudo ufw allow 5000/tcp
```

### 3. Запустите проект
```bash
./run.sh
```

### 4. Откройте интерфейс с другого компьютера
В браузере на другом ПК в той же сети перейдите по адресу:
```
http://192.168.1.42:5000
```
(замените `192.168.1.42` на реальный IP сервера)

Важно: открывайте именно `http://<IP>:5000`, а не файл `index.html` с диска, иначе запросы к API не сработают из-за ограничений протокола `file://`.

## API бэкенда

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/sessions` | Список сессий |
| POST | `/api/sessions` | Создать сессию `{ "title": "..." }` |
| GET | `/api/sessions/<id>` | История сообщений сессии |
| POST | `/api/sessions/<id>/msg` | Отправить сообщение (multipart: `message`, `images[]`) |
| DELETE | `/api/sessions/<id>` | Удалить сессию |
| GET | `/uploads/<file>` | Отдача загруженного изображения |

## Требования

- Ubuntu (или WSL с Ubuntu)
- curl
- Python 3 + pip
- Ollama + модель `gemma3` (около 4–9 ГБ в зависимости от размера модели)

## Примечание

Диск `D:` в примерах указан как `/mnt/d/aotk_project` для WSL. Если вы работаете на нативном Ubuntu, скопируйте папку `aotk_project` в удобное место и запускайте `setup.sh` оттуда.
